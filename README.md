# Paradise Nursery - Shopping Application

A dynamic web application for an online plant shop built with React and Redux Toolkit.

## Features
- **Landing Page**: Welcome screen with company introduction and direct link to shopping.
- **Product Listing**: Categorized houseplants with dynamically updating cart status.
- **Shopping Cart**: Real-time total calculation, quantity adjustment, and item deletion using Redux.

## Tech Stack
- React
- Redux Toolkit & React-Redux
- CSS3
